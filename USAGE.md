# Руководство по использованию PDF to JSON

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Базовое использование

```bash
python pdftojson.py -i ./input_pdfs -o ./output_json
```

## Подробное руководство

### Параметры командной строки

#### Обязательные параметры

- `-i, --input` - Путь к директории с PDF-файлами
- `-o, --output` - Путь к директории для сохранения JSON-файлов

#### Опциональные параметры

- `-v, --verbose` - Включить подробный вывод информации о процессе
- `-r, --recursive` - Рекурсивный поиск (включено по умолчанию)
- `--no-recursive` - Отключить рекурсивный поиск

### Примеры использования

#### Базовая конвертация

```bash
python pdftojson.py -i ./pdfs -o ./json
```

#### С подробным выводом

```bash
python pdftojson.py -i ./pdfs -o ./json --verbose
```

#### Без рекурсии (только файлы в указанной директории)

```bash
python pdftojson.py -i ./pdfs -o ./json --no-recursive
```

#### Полный путь к директориям

```bash
python pdftojson.py \
  --input /home/user/documents/laws/pdf \
  --output /home/user/documents/laws/json \
  --verbose
```

## Структура выходного JSON

Программа создает JSON-файлы следующей структуры:

```json
{
  "metadata": {
    "filename": "название_файла.pdf",
    "title": "ЗАКОН РЕСПУБЛИКИ КАЗАХСТАН О ...",
    "date": "18.11.2015",
    "processing_date": "2025-10-30T12:00:00.000000"
  },
  "content": {
    "articles": [
      {
        "article_number": "1",
        "title": "Основные понятия",
        "paragraphs": [
          {
            "number": "1",
            "text": "Текст параграфа...",
            "subparagraphs": [
              {
                "number": "1",
                "text": "Текст подпункта..."
              }
            ]
          }
        ],
        "notes": [
          "Текст примечания..."
        ]
      }
    ]
  }
}
```

## Программное использование

Вы также можете использовать модули программы в своем коде:

```python
from pdftojson import PDFToJSONConverter

# Создаем конвертер
converter = PDFToJSONConverter(verbose=True)

# Конвертируем директорию
converter.convert_directory(
    input_dir='./pdfs',
    output_dir='./json',
    recursive=True
)

print(f"Обработано: {converter.processed_count}")
print(f"Ошибок: {converter.error_count}")
```

Подробные примеры см. в файле `example_usage.py`.

## Поддерживаемые форматы

### Типы документов

- Законы Республики Казахстан
- Кодексы РК
- Конституция РК
- Указы Президента РК
- Постановления Правительства РК
- Другие нормативные правовые акты

### Форматы дат

Программа распознает следующие форматы дат:

- `от 18 ноября 2015 года`
- `от 18.11.2015`
- `18.11.2015 г.`
- `принят 18 ноября 2015`

### Структурные элементы

- **Статьи** - `Статья 1. Название`
- **Параграфы** - `1. Текст параграфа`
- **Подпункты** - `1) текст подпункта`
- **Примечания** - `Примечание:`, `Сноска:`

## Особенности работы

### Кириллица и спецсимволы

Программа корректно обрабатывает:
- Кириллицу (русский и казахский алфавиты)
- Специальные символы: №, §, —, «, », и др.
- Различные типы кавычек и тире
- Неразрывные пробелы

### Обработка ошибок

- Программа продолжает работу при ошибке в одном файле
- Все ошибки выводятся в stderr
- Код возврата: 0 - успех, 1 - были ошибки

### Производительность

- Обработка производится последовательно файл за файлом
- Для больших файлов может потребоваться время
- Рекомендуется использовать флаг `-v` для отслеживания прогресса

## Решение проблем

### Ошибка: "Директория не существует"

Убедитесь, что путь к входной директории указан правильно:

```bash
ls -la /path/to/input/directory
```

### Ошибка при чтении PDF

Проверьте, что:
1. Файл действительно является PDF
2. Файл не поврежден
3. Файл не защищен паролем

### Кириллица отображается некорректно

Убедитесь, что:
1. Используется Python 3.7+
2. Установлены все зависимости из requirements.txt
3. Консоль поддерживает UTF-8

## Примеры реальных сценариев

### Конвертация архива законов

```bash
# Архив с законами за несколько лет
python pdftojson.py \
  -i /data/laws/2020-2025 \
  -o /data/laws_json \
  -v
```

### Конвертация одного кодекса

```bash
# Отдельный файл
mkdir -p ./temp_input ./temp_output
cp "Гражданский кодекс РК.pdf" ./temp_input/
python pdftojson.py -i ./temp_input -o ./temp_output
```

### Пакетная обработка по категориям

```bash
# Обработка разных категорий
for category in laws codes decrees; do
  python pdftojson.py \
    -i ./pdfs/$category \
    -o ./json/$category \
    --verbose
done
```
