# Kazakhstan Space Programs Website

A beautiful, modern website showcasing Kazakhstan's space exploration heritage and achievements, featuring an interactive space-themed minigame.

## Features

### 🌟 Website Sections

1. **Hero Section**
   - Stunning animated starfield background
   - Eye-catching title with gradient effects
   - Quick access to the rocket game

2. **About Kazakhstan's Space Legacy**
   - Overview of Kazakhstan's role in space exploration
   - Global partnerships and collaborations
   - Innovation and technology development

3. **Milestones & Achievements Timeline**
   - Interactive timeline from 1957 to present
   - Key historical moments including Sputnik and Gagarin's flight
   - Modern satellite deployments and achievements

4. **Baikonur Cosmodrome**
   - Detailed information about the world's first space launch facility
   - Historic launches and missions
   - Statistics and impressive facts

5. **Interactive Rocket Game**
   - Fun space-themed minigame
   - Control a rocket, avoid asteroids, collect stars
   - Score tracking and lives system

### 🎮 Game Controls

- **Arrow Keys** or **WASD** - Move the rocket
- **Start Mission** - Begin the game
- **Pause/Resume** - Pause the game
- **Restart** - Reset and start over

### 🎯 Game Objective

- Avoid falling asteroids (☄️) or lose a life
- Collect stars (⭐) to earn points (+10 per star)
- Survive as long as possible to get the highest score
- Game difficulty increases as your score grows
