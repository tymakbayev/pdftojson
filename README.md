# PDF to JSON - Парсер казахстанских законодательных актов

Программа для рекурсивного сканирования директорий, поиска PDF-файлов с законами, кодексами и нормативными правовыми актами Республики Казахстан, и их преобразования в структурированный JSON-формат.

## Возможности

- ✅ Рекурсивное сканирование директорий и поддиректорий
- ✅ Поддержка кириллицы и специальных символов (№, §)
- ✅ Извлечение метаданных (название закона, дата принятия)
- ✅ Парсинг структуры документа (статьи, пункты, подпункты, примечания)
- ✅ Корректная обработка русскоязычного текста
- ✅ Сохранение в JSON с правильной кодировкой UTF-8

## Установка

### Рекомендуемый способ (виртуальное окружение)

```bash
# Создать виртуальное окружение
python3 -m venv venv

# Активировать виртуальное окружение
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows

# Установить зависимости
pip install -r requirements.txt
```

### Альтернативный способ (прямая установка)

```bash
pip install -r requirements.txt
```

**Важно:** Для максимальной точности парсинга используется библиотека `pdfplumber`, которая обеспечивает высококачественное извлечение текста из PDF-файлов с сохранением структуры и форматирования.

## Использование

```bash
python pdftojson.py --input /path/to/pdf/directory --output /path/to/output/directory
```

### Параметры

- `--input` или `-i`: Директория с PDF-файлами (обязательный)
- `--output` или `-o`: Директория для сохранения JSON-файлов (обязательный)
- `--recursive` или `-r`: Рекурсивный поиск в поддиректориях (по умолчанию: True)
- `--verbose` или `-v`: Подробный вывод

### Пример

```bash
python pdftojson.py -i ./pdfs -o ./output -v
```
